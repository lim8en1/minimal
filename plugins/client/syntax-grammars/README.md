# syntax-grammars

The tree-sitter grammars code blocks are highlighted with.

## What it adds

Syntax grammars for cpp, python, javascript, typescript, bash, json, yaml,
rust and go. Each brings its node-type table, the positions that name a
function (so `foo` in `foo()` colors as one) and the fence labels that also
mean it (`py`, `sh`, `yml`, ...). The highlighter is core's; with this plugin
disabled, code blocks render plain.

## Configuration

None.
